# Android Codex / Android Agent / Android Chat

完全本地的 AI 聊天客户端（Android），支持多模型对话、内置图片/视频生成、实时语音/视频通话、方言角色、记忆插件等能力。APK 完全打包到手机，除 AI 接口外无需任何第三方依赖。

## 功能特性

- **多模型对话**：OpenAI 兼容接口，自定义 Base URL / API Key / 模型，支持流式回复
- **AI 生图 / 生视频**：支持多张图片同时添加、单图图生图 / 图生视频、多图生成视频，预览可缩放 / 保存 / 重播；内置媒体参数配置（图片像素 / 视频分辨率 / 时长），生成进度实时显示（"生成中，请稍后" + 百分比）
- **实时语音 / 视频通话**：离线语音识别（Vosk）+ 系统 TTS 朗读，拨号动画、镜头切换、语速调节，支持键盘输入与长按录音，支持说书 / 唱歌 / 讲故事表演模式
- **通话互动角色**：自定义角色（人设 / 音色 / 方言 / 语速），支持真方言发音，男声女声分明（音色匹配 + 性别音高调节）
- **记忆插件**：跨会话记录所有操作，记忆上限可配置
- **内置插件体系**：设置页「插件」统一管理，插件列表可随时开关；右下角「+」添加脚本插件：上传 .sh / .py / .js / .lua 脚本即成为可调用插件（脚本在手机本地执行，Python 依赖 pip 自动安装，触发指令交 AI 自动完善）；预设插件带「内置」标识不可删除
- **媒体下载 DNS 加固**：生成结果下载时遇到系统 DNS 解析失败（如 Unable to resolve host platform-outputs.agnes-ai.space）时，自动走 DoH 多源解析（阿里 / DNSPod / Cloudflare / Google）按 IP 直联重试，无需改配置
- **应用索引（含复杂指令索引）**：App 启动自动枚举全部已安装应用并缓存，聊天里说「打开抖音搜索华为手机并点进第一个视频」「在淘宝搜索手机壳」「去哔哩哔哩找一下我的关注」等复杂指令也能被本地索引识别（自动抽取句中应用名 + 动作词判定，无需联网）
- **内置 Python 运行时（应用内直跑，零权限）**：Python 3.14 解释器 + 标准库完全内置（非 Termux APK），启动后台自动解压到 App 私有目录，并以 JNI（dlopen）方式在应用内直接执行——不需要 Root / 无线调试 / Shizuku / 安装 Termux，也无需点击任何按钮；SELinux 收紧禁止执行私有目录的 ROM 同样可运行。内置引擎仅含 Python 标准库：turtle / tkinter 等 GUI 库与 numpy / matplotlib / pip 不可用，涉及此类需求时请让 AI 改用纯标准库实现
- **聊天代码块一键运行（元宝式）**：AI 回复中的代码块带 ▶ 运行按钮，Python / JavaScript / Shell / Lua / SQL 代码直接在对话里实时执行并展示到聊天流（stdout/stderr 回显为回复），执行失败时卡片会显示中文原因（缺库 / 命令不存在 / 权限拒绝 / 语法与运行时错误翻译），SQL 走 Android 内置 SQLite，无需切换应用
- **联网搜索插件**（元宝同款）：输入栏一键切换 自动 / 总是开启 / 关闭；搜索过程状态化展示（正在全网搜索 → 已找到 N 篇相关内容 → 生成回答），回答内嵌 [N] 编号引用，气泡底部自动渲染可点击的「参考资料」卡片；数据源自动适配国内网络（搜狗 → Bing RSS → 百度 → DuckDuckGo 兜底）
- **思考深度**（Codex 同款）：输入栏胶囊切换 低 / 中 / 高 / 极高（映射 `reasoning_effort` 参数），自动模式不额外传参，兼容任意 OpenAI 风格模型
- **无线调试一键配对**：录屏自动识别配对码秒配对，无需 root / 电脑辅助，配对后可远程控制手机（点击 / 滑动 / 输入 / 打开应用 / 读屏）；已配对但连接失败（端口变化 / 瞬时断连）自动重试重连，不再误报「未配对」；授权被撤销时聊天内一键重新配对
- **设备控制插件（类 Codex 电脑版）**：聊天内直接说「打开微信」「点一下登录」「读屏」「上滑」即可操控手机，支持打开应用（按名称解析）/ 点击坐标或文本 / 滑动 / 长按 / 双击 / 点赞视频 / 输入 / 按键 / 读屏 / 通知栏 / 锁屏；复杂指令（如「打开抖音搜索华为手机并点进第一个视频」）由内置离线智能引擎本地「读屏→决策→执行→验证」完成（自动学习技能回放 + 元素坐标记忆），本地无法解析时自动联网决策；通道优先级：Root 最高权限 → 无线调试 → Shizuku → 无障碍（免 Root）
- **Root 最高权限控制**：仅对已 root 设备生效，非 root 用户全部原有功能（无线调试一键配对、Shizuku 控制）完整保留；设置页分别显示 Root 通道与非 Root 通道状态
- **AI 修改文件**：修改完成后保留原文件格式（换行符 / BOM / 缩进 / 尾部换行），聊天内以代码块预览修改结果，附件可应用内查看并一键保存到 下载/XS智能体
- **沙盒**：拦截破坏性命令（rm -rf / 格式化 / 提权 / 写系统分区等），写路径仅限应用私有目录与 /sdcard，拦截日志可查
- **MCP 服务**：内置轻量 MCP Server（默认 127.0.0.1:8765），提供 device_info / app_status / shell_exec 工具（强制过沙盒；已 root 设备 shell_exec 默认以最高权限执行），外部可经 adb forward 连接
- **完全离线可用**：除需要网络的 AI 接口外，语音识别、合成均在本机完成

## 使用说明

### 设备控制（免 Root，二选一）

1. **无线调试通道**：开发者选项开启「无线调试」→ 设置页点「一键配对」，授权一次屏幕录制即可自动识别配对码完成配对；聊天里收到「未授权」提示时可一键重新配对。
2. **无障碍控制通道**（无需 Root / 无线调试 / Shizuku）：系统设置 → 无障碍 → 已下载的服务 → 开启「XS Chat 无障碍控制」，设置页下方状态变为「无障碍已开启」；与无线调试二选一，读屏全部基于无障碍节点树，不截图。

### 读屏机制（禁止截图查看）

读屏优先级：无障碍节点树（秒出）→ uiautomator 节点 dump → dumpsys 文本 / 窗口视图 → 内置像素级 OCR（内置 chi_sim + eng 离线识别，节点树不可用时才截屏识别）。聊天说「读屏」「看看屏幕」即可查看当前屏幕内容。

### 复杂指令（离线智能）

「打开抖音搜索华为手机并点进第一个视频」「在淘宝搜索手机壳」「给张三发微信消息」等复杂指令已内置到应用索引（本地识别，不依赖联网）并交由离线智能引擎本地完成：读屏 → 决策 → 执行 → 验证循环，自动学习成功动作序列（技能回放）与元素坐标记忆；本地无法解析时自动转已配置模型联网决策。

### 脚本插件（上传即用）

插件管理页右下角「+」选择脚本文件即可新建插件：

- **.sh**：系统 mksh 执行（含 toybox 基础工具）
- **.js**：内置 Rhino 引擎，提供 __xs 原生桥（fetchText/fetchJSON/downloadFile/writeFile/readFile/runShell 等）
- **.lua**：内置 LuaJ 引擎，提供 xs 栅
- **.py**：使用设备中的 Python3 （推荐 Termux 安装 python），填写依赖名（如 requests bs4）运行前自动 pip 安装到插件目录
- 聊天中说「用 插件名 任务」即可执行，输出回显在聊天中；删除插件时脚本目录一并清理

## 构建

```bash
# JDK 17
./gradlew assembleDebug
```

产物：`app/build/outputs/apk/debug/app-debug.apk`
