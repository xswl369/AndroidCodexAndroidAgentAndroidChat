# Android Codex / Android Agent / Android Chat

完全本地的 AI 聊天客户端（Android），支持多模型对话、内置图片/视频生成、实时语音/视频通话、方言角色、记忆插件等能力。APK 完全打包到手机，除 AI 接口外无需任何第三方依赖。

## 功能特性

- **多模型对话**：OpenAI 兼容接口，自定义 Base URL / API Key / 模型，支持流式回复
- **AI 生图 / 生视频**：支持多张图片同时添加、单图图生图 / 图生视频、多图生成视频，预览可缩放 / 保存 / 重播；内置媒体参数配置（图片像素 / 视频分辨率 / 时长），生成进度实时显示（"生成中，请稍后" + 百分比）
- **实时语音 / 视频通话**：离线语音识别（Vosk）+ 系统 TTS 朗读，拨号动画、镜头切换、语速调节，支持键盘输入与长按录音，支持说书 / 唱歌 / 讲故事表演模式
- **通话互动角色**：自定义角色（人设 / 音色 / 方言 / 语速），支持真方言发音，男声女声分明（音色匹配 + 性别音高调节）
- **记忆插件**：跨会话记录所有操作，记忆上限可配置
- **内置插件体系**：设置页「内置插件」统一管理，插件列表可随时开关；右下角「+」添加自建插件（ID / 名称 / 描述，持久化），确认后 AI 自动完善触发指令与使用说明（非流式失败自动回退流式），支持一键删除自建插件，内置插件带「内置」标识不可删除
- **应用索引**：App 启动自动枚举全部已安装应用并缓存，聊天里说「打开抖音搜索」这类带动作词的指令也能正确解析（自动裁剪「搜索 / 打开 / 查看」等后缀词命中应用）
- **联网搜索插件**：实时联网搜索返回结果标题 / 链接 / 摘要，数据源自动适配国内网络（Bing RSS 多域名优先 + DuckDuckGo 兜底，规避 ISP 劫持）
- **无线调试一键配对**：录屏自动识别配对码秒配对，无需 root / 电脑辅助，配对后可远程控制手机（点击 / 滑动 / 输入 / 打开应用 / 读屏）；已配对但连接失败（端口变化 / 瞬时断连）自动重试重连，不再误报「未配对」；授权被撤销时聊天内一键重新配对
- **设备控制插件（类 Codex 电脑版）**：聊天内直接说「打开微信」「点一下登录」「读屏」「上滑」即可操控手机，支持打开应用（按名称解析）/ 点击坐标或文本 / 滑动 / 长按 / 双击 / 点赞视频 / 输入 / 按键 / 读屏 / 通知栏 / 锁屏；复杂指令（如「打开抖音搜索华为手机并点进第一个视频」）由内置离线智能引擎本地「读屏→决策→执行→验证」完成（自动学习技能回放 + 元素坐标记忆），本地无法解析时自动联网决策；通道优先级：Root 最高权限 → 无线调试 → Shizuku → 无障碍（免 Root）
- **Root 最高权限控制**：仅对已 root 设备生效，非 root 用户全部原有功能（无线调试一键配对、Shizuku 控制）完整保留；设置页分别显示 Root 通道与非 Root 通道状态
- **AI 修改文件**：修改完成后保留原文件格式（换行符 / BOM / 缩进 / 尾部换行），聊天内以代码块预览修改结果，附件可应用内查看并一键保存到 下载/XS智能体
- **沙盒**：拦截破坏性命令（rm -rf / 格式化 / 提权 / 写系统分区等），写路径仅限应用私有目录与 /sdcard，拦截日志可查
- **MCP 服务**：内置轻量 MCP Server（默认 127.0.0.1:8765），提供 device_info / app_status / shell_exec 工具（强制过沙盒；已 root 设备 shell_exec 默认以最高权限执行），外部可经 adb forward 连接
- **完全离线可用**：除需要网络的 AI 接口外，语音识别、合成均在本机完成

## 构建

```bash
# JDK 17
./gradlew assembleDebug
```

产物：`app/build/outputs/apk/debug/app-debug.apk`
